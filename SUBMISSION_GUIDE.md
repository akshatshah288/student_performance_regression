# Publish and submit this regression assignment

Your files are complete. Your personal Kaggle notebook URL and GitHub repository URL are created after you publish under your own accounts; they have not been created here.

## Download
Download `Student_Performance_Regression_Project.zip`. On Windows, right-click and select Extract All. Open the `student-performance-regression` folder inside it. The notebook is `Student_Performance_Regression.ipynb`.

## Kaggle notebook link
1. Sign in at https://www.kaggle.com/.
2. Open https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression and choose New Notebook.
3. In the editor, choose File > Import Notebook (or Upload Notebook) and select `Student_Performance_Regression.ipynb`.
4. Name it `Student Performance - Linear Ridge and Lasso Regression`.
5. Check the Input/Data panel for the source dataset. If missing, choose Add Input/Add Data and search `nikhil7280/student-performance-multiple-linear-regression`.
6. Run all cells. A CPU session is sufficient; no GPU is needed. Verify the comparison table and charts appear without errors.
7. Choose Save Version > Save & Run All, or the equivalent run-and-save option. Wait until the saved run finishes successfully.
8. Use Share/visibility settings to make the notebook Public if your teacher requires public access.
9. Open the saved notebook page and copy its actual URL, normally shaped like `https://www.kaggle.com/code/YOUR_USERNAME/YOUR_NOTEBOOK_SLUG`.
10. Test the link in an incognito window. Menu names can vary slightly.

## GitHub repository link
1. Sign in and open https://github.com/new.
2. Create a repository named `student-performance-regression`. Select Public if your teacher needs public access, and add a starter README.
3. Open Add file > Upload files.
4. Drag the contents of the extracted project folder into the upload area: notebook, README.md, requirements.txt, SUBMISSION_GUIDE.md, data folder and outputs folder. The supplied README replaces the starter README. Upload the extracted contents, not just the ZIP.
5. Enter a commit message such as `Add regression model comparison assignment` and commit the changes. If GitHub proposes a branch and pull request, finish and merge it so the files appear on the default branch.
6. Open the notebook on GitHub and confirm saved tables and charts are visible. GitHub displays saved outputs; it does not execute the notebook.
7. Copy the actual repository URL, normally shaped like `https://github.com/YOUR_USERNAME/student-performance-regression`.
8. Add your published Kaggle notebook URL to README.md using the edit/pencil button. You can also add the GitHub URL to the first Markdown cell of your Kaggle notebook and save another version.
9. Test both links in an incognito window. If your teacher requires private access, follow their collaborator-access instructions instead.

## What to submit
- `Student_Performance_Regression.ipynb` if a notebook upload is requested.
- Your published Kaggle notebook link.
- Your GitHub repository link.
- Dataset source link: https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression
- The required metrics and 2–3 sentence conclusion are already in the notebook. Separate copies are in `outputs/model_comparison.csv` and `outputs/conclusion.md`.

Replace example URL placeholders with the real URLs from your accounts. The dataset source link is not a substitute for your own notebook link.
